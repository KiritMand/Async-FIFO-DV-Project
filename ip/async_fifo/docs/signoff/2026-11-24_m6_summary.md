- **Scope.** This is the **SO-2 run** (vplan §7): the same 1,600 runs as M5 (200 seeds × 7 tests
  plus the 200 directed aligned-thrash runs), now with every simulation assertion enabled:
  - the scoreboard and the stimulus self-checks of M3–M5;
  - the 10 white-box assertions inside the DUT (`rtl/async_fifo_props.svh`, `ASYNC_FIFO_PROPS`);
  - the 8 e2e assertions and the 9 `asm_` testbench checks of `sva/async_fifo_e2e_props.sv`;
  - the 8 concurrent twins of `sva/async_fifo_sva_concurrent.sv` (`cast_` labels).
  It also completes **SO-1**: 150/150 planned bins, and 15/15 simulation cover properties hit.
- **Source.** git `d15f750` plus the M6 changes in the working tree, committed as the M6 commit.
- **Reproducibility.** `make regress RECHECK=3` reran 3 randomly chosen runs from their printed
  commands, and all 3 logs were byte-identical:
  - `make sim TEST=smoke_test SEED=87 SIM=verilator ASIZE=4 DSIZE=8`
  - `make sim TEST=random_rates_test SEED=15 SIM=verilator ASIZE=4 DSIZE=8`
  - `make sim TEST=fill_to_full_test SEED=144 SIM=verilator ASIZE=4 DSIZE=8`
- **Two reference models agree.** Four covers of the e2e checker count the same events as M5
  covergroup bins that are sampled from the scoreboard, and every total is equal. That means the
  checker's true fill (its own counts of accepted operations) and the scoreboard's same-timestamp
  rule agree at each of these edges:

  | Cover (e2e checker) | Covergroup bin (scoreboard) | Count |
  |---|---|---|
  | `cov_F04_blocked_write_at_full` | `cg_attempts.cp_blocked.write_at_full` | 54,600 |
  | `cov_F05_blocked_read_at_empty` | `cg_attempts.cp_blocked.read_at_empty` | 48,890 |
  | `cov_F08_wfull_lag` | `cg_flags.cp_flag_event.wfull_lag` | 87,862 |
  | `cov_F08_rempty_lag` | `cg_flags.cp_flag_event.rempty_lag` | 89,057 |

- **Cost of the assertions.** Mean run time rose about 15% (for example `fill_to_full_test`
  0.63 → 0.73 s). The wall time below includes this run's rebuild (275 s), so the 1,600 runs took
  about 160 s, against 138 s in M5, which reused an existing build. Code coverage of the RTL is
  unchanged (the property files are excluded from it).
- **Negative tests** (`docs/sva_negative_tests.md`, `make sva-neg`): every simulation assertion
  fires when broken on purpose (25/25), and so does every concurrent twin (8/8).
