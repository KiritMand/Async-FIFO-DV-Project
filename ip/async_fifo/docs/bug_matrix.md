Generated by `common/scripts/bug_matrix.py` (`make bugs`) on 2026-11-25; do not edit by hand. Bugs, predictions and explanations: `ip/async_fifo/bugs/bugs.toml`; patches: `ip/async_fifo/bugs/*.patch` (against tag `rtl-v1`). Plan: vplan §6.

**Methods.** Each bug runs through these checks:
- **Static.** `make lint` (Verilator `-Wall`) and `make synth` (Yosys `check -assert` and a flop count).
- **Structural CDC.** `make cdc` (`common/scripts/cdc_check.py`, rules R1–R3 on the Yosys netlist; waivers in `constraints/cdc.toml`).
- **Sim: UVM checks only.** `make regress SVA=0` builds the UVM testbench with `--no-assert`, which leaves the scoreboard and the test-level checks. It runs 7 tests × seeds 1–20 = 140 runs at ASIZE=4, DSIZE=8.
- **Sim: all assertions.** The same runs with the white-box, e2e and `asm_` assertions on (the SO-2 build). The first assertion failure stops a run, so the catcher listed is the first check to fire.
- **Formal** at ASIZE=2, DSIZE=4:
  - `bmc_bugs`: the spec properties without the invariants, depth 20, `--keep-going`. It lists every label that fails, with its step.
  - `prove`: k-induction with the invariants.
  - `cover`: which covers stay reachable. Cover mode ignores assertions (toolchain T19).

Reproduction commands run from the repository root. ($PWD is the root.)

**Reading a cell.** ✓ means the result matched the prediction written before any run; **≠ x** means the prediction was x. Simulation cells give failing runs out of the total. `e2e @n` means an end-to-end (ports-only) property failed, first at formal step n. `white-box` means only properties on internal signals failed. Every ≠ is explained under its bug. A `cast_` label is the concurrent twin of the e2e assertion with the same name (simulation only); both fail in the same time step, and the log lists the twin first.

## Findings

1. **Every bug is caught by some method; no method catches every bug.**

   | Method | Bugs caught | Missed |
   |---|---|---|
   | Simulation, UVM checks only (scoreboard and test checks) | 8 of 12 | B07, B08, B09, B12 |
   | Simulation with every assertion | 11 of 12 | B08 |
   | Formal, spec properties to depth 20 | 11 of 12 (ten through an e2e property) | B08 |
   | Structural CDC check | 2 of 12 (B08, B09) | the ten functional bugs |

   In formal, B07 fails only white-box properties. Lint and synth also flag B07 and B08, but only
   by accident: each leaves a register unread. B08 escapes every functional method, including the
   k-induction proof.
2. **Assertions on the flags turn luck into certainty.** Failing runs, UVM checks only → with
   every assertion:
   - B05: 75 → 140
   - B12: 0 → 140
   - B06: 114 → 140
   - B01: 96 → 138
   - B11: 99 → 118
   - B09: 0 → 41

   The scoreboard sees a wrong flag only when the stimulus acts on it at the wrong edge. A property
   on the flag sees the flag itself.
3. **For data-path bugs, assertions add timing, not detection.** B03, B04 and B10 fail in exactly
   the same runs with and without assertions. The assertion (`ast_F14_rdata_stable`,
   `ast_F05_blocked_read_holds_rptr`) fires earlier than the scoreboard's mismatch, which helps
   locate the bug, but finds no new failures.
4. **Regular tests can hide bugs.** B10 (memory addressed with gray bits) passes every directed
   test. Filling exactly DEPTH entries from empty keeps the live window aligned at pointer 0 or
   16, where no two live entries share a slot. B04 needs a read attempt at empty, which
   `fill_to_full_test` and `thrash_full_test` never make. The random tests carry these detections.
5. **CDC bugs are a separate class.** RTL simulation and RTL formal have no metastability.
   - B07 (binary pointer crossing) is seen only by the source-side white-box
     `ast_F09_wptr_cdc_one_bit`; no e2e property fails in simulation or in formal.
   - B08 (one synchronizer stage) is seen by nothing functional: only the structural check (R2)
     and a cover that becomes unreachable.
   - B09 (synchronizer on the source clock) shows up functionally only through a latency side
     effect: `ast_F08_rempty_exact`, in 41 of 140 runs and in formal. Its cause is found by the
     structural rules R1/R3 and the white-box `ast_F11_rsync_on_rclk`.

   See `docs/interview_notes.md` (metastability).
6. **Covers catch "safe but wrong".** `cov_F08_wfull_lag_k_minus_1` has 1,866 hits on rtl-v1 and
   none on B08. Five covers that need fill = DEPTH become unreachable on B11.
7. **Formal is the fastest finder.** At ASIZE=2, every functional bug fails `bmc_bugs` within 17
   steps (B12 at step 1), each run in minutes. `prove` fails or is inconclusive for every bug
   except B08.
8. **The matrix found a testbench gap (B12).** The first `rclk` edge after reset release never
   carries a read, because the driver sees the release one edge late. The write side works the
   same way. A fix is proposed under B12; it is the owner's decision, because it changes the
   stimulus behind SO-1/SO-2.
